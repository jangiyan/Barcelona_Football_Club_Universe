# Image Manifest — Barça Universe

**Status: no photos have been added yet.** The website already has a place waiting for every image below.
Until you add a file, that spot simply keeps its original gradient/initials/emoji look. Nothing is broken.

This list was prepared without internet access to Wikimedia, so **no specific photo has been chosen or checked for you**.
The links below are *search links* — they open Wikimedia Commons search results. You pick a photo and check its licence yourself (see README.md → "Adding images").

## How to use this list (3 steps)
1. Click a search link, choose a good photo, click it, then click **Download** (a medium size is fine).
2. Rename the file to the **exact filename** in the table (lowercase, with hyphens). `.jpg`, `.png` or `.webp` all work — just keep the name the same.
3. Put it in the `assets/images/` folder and refresh the page. Then add one row to the attribution table in README.md.

You do **not** need to edit any HTML or CSS.

## Notes
- Total image slots: **50**. Some files are reused on several pages, so you download each only once.
- Recommended file size: under about 300 KB each (compress at https://squoosh.app).
- Always prefer images marked **Public domain** or **CC0**, or **CC BY / CC BY-SA** (these need credit). Avoid anything marked "non-commercial" or "no derivatives" or "fair use".
- The club crest is a trademark. Commons may host it with a trademark note; read it before using it.
- The jerseys page contains a sentence saying kit visuals are CSS drawings, not photos. Once you add real kit photos, you may want to reword it.
